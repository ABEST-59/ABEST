# 🚀 Google Cloud Directory Sync (GCDS) - Configuration & Documentation

Ce dépôt contient la documentation de référence et la configuration pour la synchronisation entre l'annuaire **Active Directory (LDAP)** et la console d'administration **Google Workspace**.

---

## 📋 Aperçu du Projet

* **Outil** : Google Cloud Directory Sync (GCDS)
* **Version** : 5.0.50
* **Domaine Google Principal** : `abest.ovh`
* **Serveur LDAP / AD** : `pldc1.ldap.abest.ovh`

---

## ⚙️ Détails de la Configuration

### 1. Configuration du Domaine Google (`Google Domain Configuration`)

| Paramètre | Valeur |
| :--- | :--- |
| **Primary Domain Name** | `abest.ovh` |
| **Read Timeout** | `20` secondes |
| **Statut d'autorisation** | ✅ **Authorized** (OAuth 2.0) |

---

### 2. Configuration Active Directory (`LDAP Configuration`)

| Paramètre | Valeur |
| :--- | :--- |
| **Server Type** | `MS Active Directory` |
| **Connection Type** | `LDAP+SSL` (LDAPS) |
| **Host Name** | `pldc1.ldap.abest.ovh` |
| **Port** | `636` |
| **Authentication Type** | `Simple` |
| **Authorized User** | `ABEST\gcds` |
| **Base DN** | `OU=ABEST,DC=ldap,DC=abest,DC=ovh` |

---

### 3. Périmètre de Synchronisation (`General Settings`)

Éléments actifs pour la synchronisation automatique :
* [x] **Organizational Units** (Unités d'organisation)
* [x] **User Accounts** (Comptes utilisateurs)
* [x] **Groups** (Groupes de messagerie & distribution)

---

### 4. Unités d'Organisation (`Organizational Units`)

#### Mapping des OU
* **LDAP DN** : `OU=ABEST,DC=ldap,DC=abest,DC=ovh` $\rightarrow$ **Google Org Unit** : `ABEST`

#### Règles de Recherche (`Search Rules`)
* **Description Attribute** : `description`
* **Scope** : `SUBTREE`
* **Filter** : `(objectClass=organizationalUnit)`

---

### 5. Comptes Utilisateurs (`User Accounts`)

#### Attributs Utilisateurs
* **Primary Email Attribute** : `userPrincipalName`
* **Unique Identifier Attribute** : `objectGUID`
* **Alias Address Attributes** : `proxyAddresses`
* **Given Name** : `givenName`
* **Family Name** : `sn`
* **Display Name** : `displayName`

#### Politique de Suppression / Suspension
* 🔘 **Suspend Google domain users not found in LDAP, instead of deleting them** *(Les utilisateurs supprimés de l'AD sont suspendus sur Google, pas supprimés)*.
* [x] **Don't suspend or delete Google domain super admins not found in LDAP** *(Protection des comptes super administrateurs Google)*.

#### Gestion des Mots de Passe
* **Synchronize Passwords** : `Only for new users`
* **Password Attribute** : `userPassword`
* **Encryption Method** : `SHA1`

#### Règle de Recherche Utilisateurs (`Search Rules`)
* **Scope** : `SUBTREE`
* **Filter** :
  ```ldap
  (&(objectCategory=person)(objectClass=user)(userPrincipalName=*)(!(userAccountControl:1.2.840.113556.1.4.803:=2)))
